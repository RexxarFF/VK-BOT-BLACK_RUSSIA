# AP Contest Bot v3.1

VK-бот для конкурсов Агентов Поддержки. Версия v3.1 работает **полностью внутри VK** — без сайта, домена и VK Mini Apps.

## Что умеет v3.1

### Для обычного Агента Поддержки
- ЛС бота с одной аккуратной панелью.
- Профиль: должность, количество 1/2/3 мест, число завершённых конкурсов.
- Рейтинг активного конкурса и собственные баллы/место.
- Подача отчёта полностью в ЛС.
- Форма отчёта идёт в одном редактируемом сообщении:
  1. Nick_Name.
  2. Дата выполненной работы.
  3. Скриншот как фотография VK.
  4. Предпросмотр.
  5. Подтверждение.
- После подтверждения готовый отчёт с фотографией публикуется в назначенную беседу отчётов.
- Хелпер не видит историю своих отчётов в боте.

### Для руководства
- В ЛС руководства отображаются все основные разделы: профиль, рейтинг, отчёт, конкурс, Агенты, баллы, должности и настройки.
- Отдельная беседа руководства с одной редактируемой панелью.
- Создание конкурса.
- Настройка названия, описания и даты окончания конкурса.
- Шаблоны конкурсов. Сейчас есть один: **по конкурсным баллам**.
- Добавление участников через VK ID / @username / упоминание / ссылку + Nick_Name.
- Отдельный список всех зарегистрированных Агентов Поддержки: добавление, профиль, должность, добавление в конкурс и исключение из системы.
- Отдельный список участников активного конкурса.
- Управление участником через кнопки.
- Управление баллами через список участников и кнопки `-10 -5 -1 / +1 +5 +10` или своё значение.
- Завершение конкурса и автоматическое сохранение 1/2/3 мест в профили участников.
- Должности, уровни и гибкие права.
- Все пользовательские ошибки написаны по-русски.
- Команды начинаются только с `/` и имеют английские названия.


### Что исправлено в v3.1
- Старые постоянные клавиатуры v1/v2 автоматически скрываются в настроенных беседах и при первом взаимодействии в любом peer.
- Ввод во время мастеров/форм всегда имеет приоритет над командами и больше не может вызвать «Неизвестная команда».
- Сообщения с введёнными VK ID, Nick_Name, датами, названиями, уровнями и баллами удаляются в фоне после обработки, когда VK разрешает удаление.
- Удаление служебного ввода больше не блокирует основной ответ бота, поэтому интерфейс реагирует быстрее.
- Уровни должностей переведены на понятную шкалу 1–10. Старые кастомные уровни автоматически приводятся к этому диапазону.

## 1. Что загрузить на Bothost

Загрузите содержимое папки проекта так, чтобы в корне находились:

```text
main.py
Dockerfile
requirements.txt
.env
app/
tests/
```

Сайт и домен **не включайте** — v3.1 использует только VK Long Poll.

## 2. Переменные окружения

На Bothost откройте настройки бота → переменные окружения и заполните:

```env
VK_GROUP_TOKEN=ТОКЕН_СООБЩЕСТВА
VK_GROUP_ID=ID_СООБЩЕСТВА
BOT_OWNER_IDS=ВАШ_ЛИЧНЫЙ_VK_ID
DATA_DIR=/app/data
MAX_POINTS_CHANGE=1000
LOG_LEVEL=INFO
```

Пример:

```env
VK_GROUP_ID=240938953
BOT_OWNER_IDS=123456789
```

`VK_GROUP_ID` указывается **без минуса**.

## 3. Настройки сообщества VK

В сообществе включите:

1. **Сообщения сообщества**.
2. **Настройки для бота → Возможности ботов**.
3. Возможность добавлять сообщество в беседы.
4. **Работа с API → Long Poll API → Включено**.
5. В типах событий обязательно включите:
   - входящие сообщения (`message_new`);
   - события callback-кнопок / `message_event`.

Если бот добавлен в беседу, дайте сообществу доступ к сообщениям беседы.

## 4. Первый запуск

Перезапустите проект на Bothost.

В логах должно быть:

```text
Запуск VK-бота Агентов Поддержки v3.1
Сайт и Mini App отключены — бот работает только через VK Long Poll.
```

Если появляется `longpoll for this group is not enabled`, включите Long Poll API в настройках сообщества.

## 5. Назначить беседу руководства

Добавьте сообщество в беседу руководства.

От аккаунта, VK ID которого указан в `BOT_OWNER_IDS`, отправьте:

```text
/setchat leadership
```

Команда удалится, а бот создаст одну панель управления.

Если панель потерялась:

```text
/panel
```

## 6. Назначить беседу отчётов

Добавьте сообщество в беседу, куда должны попадать готовые отчёты.

От владельца отправьте:

```text
/setchat reports
```

Бот создаст одно служебное сообщение с callback-кнопкой:

```text
📝 Подать отчёт
```

При нажатии вопросы не появляются в общей беседе — форма приходит пользователю в ЛС бота.

## 7. Беседа логов — необязательно

Если нужна отдельная беседа действий руководства:

```text
/setchat logs
```

Если её не назначать, внутренний audit-log всё равно сохраняется в JSON.

## 8. Создать конкурс

Лучше через панель руководства:

```text
🏆 Конкурс
→ ➕ Создать конкурс
```

Бот спросит:

1. Название.
2. Описание.
3. Дату окончания.
4. Шаблон.

Сейчас доступен шаблон:

```text
⭐ По конкурсным баллам
```

Чем больше баллов — тем выше место.

То же действие командой:

```text
/newcontest
```

## 9. Добавить Агента или участника конкурса

Чтобы просто зарегистрировать Агента в системе, в панели руководства откройте:

```text
👥 Агенты
→ ➕ Добавить АП
```

Сначала отправляется VK ID / ссылка / @username / упоминание, затем Nick_Name. После этого у Агента появляется доступ к своему профилю и меню бота.

Быстрая команда для регистрации без конкурса:

```text
/adduser https://vk.com/username Felix_Wraith
```

Чтобы добавить человека именно в активный конкурс, откройте:

```text
🏆 Конкурс
→ 👥 Участники конкурса
→ ➕ Добавить
```

Либо используйте команду ниже. При `/addmember` новый Агент одновременно регистрируется в системе, если его там ещё не было.

Быстрая команда:

```text
/addmember https://vk.com/username Felix_Wraith
```

Поддерживаются:

```text
/addmember 123456789 Felix_Wraith
/addmember id123456789 Felix_Wraith
/addmember @username Felix_Wraith
/addmember https://vk.com/username Felix_Wraith
```

Если Агент уже зарегистрирован, его также можно открыть через `👥 Агенты` и нажать `🏆 Добавить в конкурс` — Nick_Name подставится из его профиля автоматически.

## 10. Управление баллами

Через панель:

```text
⭐ Баллы
→ выбрать Агента
```

Доступны кнопки:

```text
-10   -5   -1
+1    +5   +10
✏️ Другое значение
```

Быстрая команда:

```text
/points https://vk.com/username +5 Дополнительная работа
/points 123456789 -2 Нарушение условий конкурса
```

Баллы не могут уйти ниже нуля.

## 11. Завершение конкурса

Через панель:

```text
🏆 Конкурс
→ 🏁 Завершить конкурс
```

или:

```text
/finishcontest
```

После завершения бот фиксирует итоговый рейтинг. Первое, второе и третье места записываются в статистику профилей.

## 12. Должности и права

Создать должность:

```text
/addrole
```

или, например:

```text
/addrole Организатор конкурсов
```

Бот попросит уровень должности от 1 до 10.

Назначить должность:

```text
/setrole https://vk.com/username Организатор конкурсов
```

Настроить права:

```text
/setperm Организатор конкурсов
```

Появится панель с переключателями прав.

Доступные категории прав:
- профиль и просмотр конкурса;
- подача отчётов;
- просмотр / добавление / исключение участников;
- начисление / снятие баллов;
- создание / настройка / завершение конкурса;
- добавление / исключение участников конкурса;
- просмотр / создание / назначение должностей;
- настройка прав;
- настройка бота и бесед;
- просмотр служебной информации.

Должность `Владелец` нельзя назначить командой. Владельцы задаются только через `BOT_OWNER_IDS`.

## Чистота бесед

v3.1 специально сделан по принципу **single-message UI**:

- callback-кнопки не отправляют текст от пользователя в беседу;
- панель руководства редактируется вместо создания новых сообщений;
- мастер создания конкурса редактирует ту же панель;
- форма отчёта редактирует одно сообщение в ЛС;
- введённые служебные команды и ответы мастер-форм бот пытается удалить после обработки;
- технические ошибки не показываются пользователю на английском;
- обычные неизвестные сообщения в беседах бот игнорирует.

VK иногда может запретить боту удалить чужое сообщение из-за прав конкретной беседы. Это не ломает действие: бот просто продолжит работу, а ошибка удаления будет проигнорирована.

## Обновление с v2

v3.1 больше не использует FastAPI, домен и Mini App. Старые параметры `VK_APP_ID`, `VK_APP_SECRET`, `PUBLIC_BASE_URL` можно удалить.

JSON-хранилище остаётся совместимым насколько возможно: при старте v3.1 добавляет недостающие поля старым пользователям и конкурсам. Если у вас уже есть рабочие JSON-данные, не удаляйте постоянную папку `DATA_DIR` при обновлении.
